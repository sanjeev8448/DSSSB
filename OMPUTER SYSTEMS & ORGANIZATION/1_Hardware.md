Hardware refers to the physical components of a computer system that can be seen and touched. This includes input devices, output devices, the CPU, memory, and storage.

The key exam objective is to understand the function of each component, classify devices correctly, and distinguish similar concepts.

These three are particularly useful for objective questions.

Recognizes characters in an image, such as text on a scanned document.

Example: extracting printed text from a page.

### OMR — Optical Mark Recognition

Detects marks in predefined positions.

Example: checking shaded circles on an objective answer sheet.

### MICR — Magnetic Ink Character Recognition

Reads characters printed with magnetic ink.

Example: processing characters on bank cheques.

Exam trap: OCR recognizes characters, OMR detects marks, and MICR reads magnetic-ink characters.

## 3. Central Processing Unit (CPU)

The CPU is the main processor that executes program instructions and performs arithmetic, logical, and control operations.

![Processing Power](https://images.openai.com/static-rsc-4/Jjk4lg37eQu8BPulHULdUR6sQjOOn42sxHhzBOrO7ScxRRIGLkc-ack9Aw6U7zy00AJxIjX0Bcc8iceWOxd5-HMtwUcMCs5hdHQVDLGd0jcInnYs1bHYMX6feBnq0qYjcYOPjjAhGGtSbRr2nd8oC2LrX4LNG0Ij7W0xgTQCX36rDHNkaCvuRd7q4UXXLh6M?purpose=inline)

## Main CPU components

ALU — Arithmetic Logic Unit

Performs arithmetic operations, such as addition and subtraction, and logical operations, such as comparisons and Boolean logic.

CU — Control Unit

Coordinates instruction execution and controls the flow of data and signals between the CPU, memory, and other components.

Registers

Very small, fast storage locations inside the processor that temporarily hold data, addresses, instructions, or intermediate results.

Modern CPUs also contain caches, execution units, and often multiple cores. A CPU is not limited to only three physical components; ALU, CU, and registers are the traditional fundamental components commonly covered in introductory computer organization.

### Important CPU registers

|Register|Function|
|---|---|
|PC — Program Counter|Holds the address of the next instruction to be fetched, subject to control-flow changes|
|IR — Instruction Register|Holds the instruction currently being decoded or executed, depending on the processor design|
|MAR — Memory Address Register|Holds the memory address for a memory access in the traditional model|
|MDR / MBR — Memory Data / Buffer Register|Holds data being transferred to or from memory in the traditional model|
|Accumulator (ACC)|Holds intermediate arithmetic or logical results in accumulator-based architectures|

Exam trap: The PC stores an instruction address, not the instruction itself. The IR holds the instruction. Register names and exact internal roles can vary across architectures, but these are the standard textbook definitions.

### CPU clock speed and cores

- Clock speed: Measured in hertz, commonly GHz. It describes the clock's frequency, not directly the number of instructions completed per second.
    
- Core: A processing unit within a CPU. A multicore CPU can execute work across multiple cores.
    
- Cache: Small, fast memory used to keep frequently needed data and instructions close to the processor.
    

A higher clock speed does not automatically guarantee a faster computer: architecture, core count, workload, cache, memory, and power limits also matter.

### Instruction cycle

A simplified instruction cycle is:

1. Fetch: Retrieve the instruction from memory.
    
2. Decode: Determine what the instruction means.
    
3. Execute: Perform the operation.
    
4. Store / write back: Save the result when required.
    

Not every instruction follows an identical sequence, but fetch–decode–execute is the standard introductory model.

## 4. Memory

Computer memory holds instructions and data needed for processing. The key distinction is between primary memory, which is directly used by the processor during execution, and secondary storage, which retains data for longer-term use.

### A. RAM — Random Access Memory

RAM is generally volatile: its contents are lost when power is removed.

- Holds running programs and working data.
    
- Supports reading and writing.
    
- Is used as the computer's main working memory.
    

Two commonly taught types are:

- DRAM: Commonly used for main memory; stores bits using capacitors and requires refreshing.
    
- SRAM: Faster and more expensive per bit in typical implementations; commonly used in processor caches and does not require periodic refresh in the same way as DRAM.
    

### B. ROM — Read-Only Memory

ROM is non-volatile memory, meaning it retains its contents without power.

It is associated with firmware and instructions needed for hardware initialization or startup.

|Type|Key property|
|---|---|
|PROM|Programmable once after manufacture|
|EPROM|Can be erased using ultraviolet light and reprogrammed|
|EEPROM|Electrically erasable and reprogrammable|
|Flash memory|A type of electrically erasable non-volatile memory, typically erased in blocks|

Exam trap: RAM is typically volatile; ROM and flash memory are non-volatile. ROM is not necessarily impossible to rewrite—its type determines whether and how it can be reprogrammed.

### C. Cache memory

Cache stores copies of frequently used data or instructions to reduce average access time.

The traditional cache hierarchy is:

- L1: Usually the smallest and fastest cache, close to or inside each core.
    
- L2: Usually larger than L1, with higher access latency.
    
- L3: Often larger and shared across cores in many processor designs.
    

The exact hierarchy varies by processor.

### D. Memory hierarchy

Registers

Fastest, smallest

Cache (L1, L2, L3)

Main memory (RAM)

Secondary storage (SSD / HDD)

Typically slower, larger, non-volatile

As a general rule, moving down this hierarchy means greater capacity and lower cost per bit, but also longer access latency. Exact speeds and sizes depend on the system.

## 5. Storage devices

Storage devices retain data, files, applications, and operating-system information. Unlike RAM, secondary storage is non-volatile in typical computer systems.

### A. HDD — Hard Disk Drive

Magnetic storage

An HDD stores data magnetically on rotating platters. A read/write head accesses the data.

- Mechanical moving parts.
    
- Often economical for large capacities.
    
- Usually slower than an SSD for random access.
    

### B. SSD — Solid-State Drive

![Installer un SSD en plus du HDD [Résolu] - Disque dur / SSD](https://images.openai.com/static-rsc-4/Cs06ny6kzoT0ioDhD8AA6PL1mQWCEwDW5VzxXQh-XMDYNvnts3MRyr1-OzBkJ0uau_7POYCYyJOA1iqpt18jrR2VheZbOtZYK56uQc6xIV0TIbm91RFmnYVGdnAIrkQIx0KjavPG9JXYXq-OadqUzLcRjwa3quCXjk6kF1AEcP4?purpose=inline)

Flash-based storage

An SSD stores data in non-volatile flash memory.

- No moving mechanical parts.
    
- Generally faster access and lower latency than an HDD.
    
- Often more resistant to mechanical shock.
    

### C. Optical storage

![CD and DVD discs on dark background, top view](https://images.openai.com/static-rsc-4/Tv8TAao-VRI0GgCR4S1jeMbjI3N40cs5Ig4RFx39j2dYMD6MTIVVqAxWSVS41iEPdPEFfjDctIixJ0Se5v_Y4tQrecKDRDf_NB7oBM0DEtW34Wt4mUk0kdW28nPir_GITYKADtm0EFsPS_iC3l5x8VE8C2IIOLdHcFmiegEqXidnPvml5NnEZYbuRgCOUjch?purpose=inline)

Data is read or written using laser technology.

- CD: Compact Disc.
    
- DVD: Digital Versatile Disc.
    
- Blu-ray: Optical format with greater capacity than a standard DVD.
    

### D. USB flash drive and memory card

These use flash memory and are portable, non-volatile storage devices. Examples include USB pen drives and SD cards.

### E. Cloud storage

Cloud storage keeps data on remote infrastructure accessed through a network. It is a storage service rather than a specific physical device in the user's computer.

### HDD vs SSD vs RAM

|Feature|RAM|HDD|SSD|
|---|---|---|---|
|Main purpose|Working memory|Long-term storage|Long-term storage|
|Volatile?|Typically yes|No|No|
|Moving parts?|No|Yes|No|
|Typical access speed|Fastest of these three|Slowest for many access patterns|Generally faster than HDD|
|Retains data without power?|No, in ordinary DRAM|Yes|Yes|

Exam trap: SSD is not the same as RAM. Both can use semiconductor technology, but RAM serves as working memory and is usually volatile, while an SSD provides persistent storage.

## 6. Units of memory and storage

These are important for numerical MCQs.

|Unit|Meaning|
|---|---|
|Bit (b)|A binary digit: 0 or 1|
|Nibble|4 bits|
|Byte (B)|8 bits|
|KB / MB / GB / TB|Commonly used storage-capacity units|

Two unit conventions are worth distinguishing:

- Decimal: 1 kB = 1,000 bytes; 1 MB = 1,000,000 bytes.
    
- Binary: 1 KiB = 1,024 bytes; 1 MiB = 1,024 KiB.
    

Older exam questions sometimes use KB to mean 1,024 bytes. Read the question's convention carefully.

Example:

If a file contains 4,096 bytes, its size is:

\[ 4096 \div 1024 = 4\ \text{KiB} \]
