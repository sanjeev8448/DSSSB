## 1. Creative Commons (CC)

Definition: Creative Commons is a system of standardised licences that allows creators to grant the public permission to use their work under specified conditions.

It is commonly used for educational materials, photographs, music, articles, videos, and other creative content.

### Main Creative Commons conditions

|Symbol / term|Meaning|Requirement|
|---|---|---|
|BY — Attribution|Give credit to the creator|Credit must be provided as required by the licence|
|SA — ShareAlike|Share adaptations under the same or a compatible licence|Applies when distributing adaptations|
|NC — NonCommercial|Non-commercial use only|Commercial use is restricted|
|ND — NoDerivatives|No distribution of adapted material|Sharing adaptations is restricted|

### Common Creative Commons licences

|Licence|Main conditions|
|---|---|
|CC BY|Attribution|
|CC BY-SA|Attribution + ShareAlike|
|CC BY-NC|Attribution + NonCommercial|
|CC BY-ND|Attribution + NoDerivatives|
|CC BY-NC-SA|Attribution + NonCommercial + ShareAlike|
|CC BY-NC-ND|Attribution + NonCommercial + NoDerivatives; most restrictive of these six standard licences|

Example: A teacher publishes notes under CC BY. Others may generally copy and adapt the notes, including commercially, provided they meet the attribution requirements.

### Important exam points

- BY means attribution is required.
    
- SA means adaptations must be shared under the same or a compatible licence.
    
- NC restricts use to non-commercial purposes.
    
- ND restricts the distribution of adaptations.
    
- Creative Commons is not a single licence; it is a family of licences.
    

## 2. GNU General Public License (GPL)

Definition: The GNU General Public License is a free-software licence that uses the copyleft principle. It allows users to run, study, modify, and redistribute covered software, subject to its conditions.

### Key features

- Source code must be made available under the applicable GPL requirements when distributing covered software.
    
- Users may modify the software and distribute modified versions, subject to the licence.
    
- When distributing covered derivative works, the applicable GPL version generally requires those works to remain under the GPL.
    
- The GPL does not prohibit commercial use or selling copies of software.
    
- GPL-licensed software is still copyrighted; the licence grants permissions under specified conditions.
    

### Example

Suppose a developer modifies a GPL-licensed program and distributes the modified version. The developer generally must comply with the applicable GPL requirements, including providing corresponding source code under the relevant conditions.

### GPL versions

- GPL v2: An earlier widely used version.
    
- GPL v3: A later version that includes additional provisions, including those addressing certain patent and device-related restrictions.
    

Exam point: GPL is a copyleft licence. Its aim is to preserve the freedoms to use, study, modify, and redistribute covered software.

## 3. Apache License 2.0

Definition: The Apache License 2.0 is a permissive open-source software licence that allows use, modification, and redistribution under specified conditions.

It is commonly associated with projects in the Apache Software Foundation ecosystem and many other open-source projects.

### Key features

- Allows commercial and private use.
    
- Allows modification and redistribution.
    
- Does not generally require modified versions to be released under the Apache License.
    
- Includes an express patent licence from contributors, subject to its terms.
    
- When redistributing, users must comply with applicable conditions concerning the licence, copyright notices, and relevant attribution or NOTICE information.
    
- Does not require every modified version to be made open source merely because it uses Apache-licensed code.
    

### Example

A company uses an Apache-licensed software library in a commercial product. It may generally do so without publishing the entire product's source code, provided it complies with the licence's applicable conditions.

Exam point: Apache 2.0 is permissive and includes express patent-licensing provisions.

## 4. GPL vs Apache vs Creative Commons

| Feature                | Creative Commons                                       | GPL                                                  | Apache 2.0                                                           |
| ---------------------- | ------------------------------------------------------ | ---------------------------------------------------- | -------------------------------------------------------------------- |
| Main purpose           | Creative works and content                             | Software                                             | Software                                                             |
| Licence type           | Family of content licences                             | Copyleft                                             | Permissive                                                           |
| Commercial use         | Depends on the selected CC licence                     | Generally permitted                                  | Permitted                                                            |
| Modification           | Depends on the selected CC licence                     | Permitted under its conditions                       | Permitted under its conditions                                       |
| Source-code disclosure | Not primarily designed for software source code        | Required in specified distribution circumstances     | Not generally required for modified versions                         |
| Share-alike / copyleft | SA applies to adaptations when required by the licence | Copyleft requirements apply to covered distributions | No general requirement to use the same licence for modified versions |
| Patent provisions      | Depends on the relevant CC licence                     | Depends on the GPL version                           | Express contributor patent licence                                   |
## Last-minute revision

- Creative Commons: Mainly for creative works; remember BY, SA, NC, ND.
    
- GPL: Software licence using copyleft.
    
- Apache 2.0: Permissive software licence with express patent provisions.
    
- Commercial use: Generally permitted under GPL and Apache 2.0, subject to their conditions.
    
- Source code: GPL has source-code obligations in specified distribution circumstances; Apache 2.0 does not generally require modified versions to be released as open source.
    
- Common trap: Free and open-source software can still be copyrighted and subject to licence conditions.
